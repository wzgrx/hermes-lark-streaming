# 0.20.23 — 工具摘要的转义与显示边界

## 复现与修改

原 `_tool_text` 先切取字符前缀，再折叠空白、HTML/Markdown 转义，最后直接切 UTF-8 字节。存在三个展示缺陷：

1. 截断点可能落在 `&lt;`、`&amp;`、`&#x27;` 或反斜杠转义的中间，形成半截转义片段。
2. 截断后的省略号另占 3 字节，超出原函数声明的显示预算。
3. 大段空白占满前置字符窗口后，后续可见文字被无提示丢弃。例如 `run` + 大段空白 + `END` 本可显示为 `run END`，却只显示 `run`。

现在先对完整源值脱敏，再惰性折叠单行空白。每个源字符作为完整转义单元输出，逐单元计算 UTF-8 字节；确认发生省略时才预留省略号空间，回退也只回退完整单元。短文本的转义行为不变，展开步骤摘要保留原换行。没有新增依赖或字符串占位符；仍为有界前缀展示，不是完整日志导出，也不声称完整 Unicode 字素簇分段。

影响现有 V1 工具名称、64 字节命令提示、错误简述和步骤摘要。四列权重、行数优先级、失败底色、面板顺序、原生折叠 ID、13 KB 工具面板份额、28 KB/200 元素策略保持原样，不重新绘制设计图。源步骤内容与计数不改。

README 徽章升级至当前代码版本；0.20.16 介绍改为历史维护。旧真实截图仍标原版本，未冒充本轮像素验收。
